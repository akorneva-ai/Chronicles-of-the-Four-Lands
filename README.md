# Chronicles of the Four Lands

Пошаговая стратегия на Python, в которой четыре королевства управляют ресурсами, принимают решения и взаимодействуют друг с другом.

## Описание проекта

Проект представляет собой многопользовательскую пошаговую стратегию, где каждый игрок управляет своим королевством.

Игровой процесс состоит из:
- одного случайного неуправляемого события, которое влияет на состояние королевства;
- одного управляемого действия игрока, направленного на взаимодействие с другими игроками.

Цель игрока — развивать своё королевство, управлять ресурсами и достигнуть условий победы.
