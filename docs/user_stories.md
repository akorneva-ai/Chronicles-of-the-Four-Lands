# User Stories  
## «Хроники Четырёх Земель»

## 1. Назначение документа

Данный документ описывает пользовательские сценарии игры «Хроники Четырёх Земель».

User Stories отражают потребности игрока и описывают, какие возможности должна предоставлять система с точки зрения пользователя.

Документ не содержит деталей реализации и описания кода.


---

# US-1. Просмотр состояния королевства

## User Story

**Как игрок,  
я хочу видеть текущее состояние своего королевства на экране,  
чтобы понимать свои возможности и принимать стратегические решения.**

## Описание

Игрок должен постоянно видеть основные показатели своего королевства во время игры.

На игровом экране должны отображаться:

- количество зерна;
- количество денег;
- количество земли;
- количество народа;
- уровень смуты;
- текущий престиж.

Эти показатели используются игроком для оценки состояния королевства и выбора дальнейших действий.

# US-2. Получение информации о случайном событии

## User Story

**Как игрок,  
я хочу видеть произошедшее неуправляемое событие и его последствия,  
чтобы понимать изменения состояния своего королевства.**

## Описание

В начале каждого хода происходит случайное событие.

Игрок должен видеть:

- название события;
- описание события;
- изменение ресурсов после события.

Игрок использует эту информацию для выбора дальнейшей стратегии.


---

# US-3. Просмотр доступных действий

## User Story

**Как игрок,  
я хочу видеть список доступных управляемых действий,  
чтобы выбирать наиболее подходящий вариант развития королевства.**

## Описание

После наступления случайного события игрок получает возможность выбрать одно управляемое действие.

Для каждого действия должна быть доступна информация:

- название действия;
- стоимость;
- возможный эффект;
- необходимость выбора цели.


---

# US-4. Выбор управляемого действия

## User Story

**Как игрок,  
я хочу выполнять управляемые действия после получения события,  
чтобы влиять на развитие своего королевства и изменять игровую ситуацию.**

## Описание

Игрок может использовать действия для:

- восстановления ресурсов;
- развития королевства;
- снижения негативных последствий событий;
- взаимодействия с другими игроками.


---

# US-5. Взаимодействие с другими игроками

## User Story

**Как игрок,  
я хочу взаимодействовать с другими королевствами,  
чтобы применять различные стратегии развития и конкурировать за победу.**

## Описание

Некоторые игровые действия требуют выбора другого игрока в качестве цели.

Игрок должен иметь возможность:

- выбрать королевство-цель;
- применить действие к выбранному игроку;
- увидеть последствия взаимодействия.


---

# US-6. Просмотр последствий своих решений

## User Story

**Как игрок,  
я хочу видеть изменения состояния королевства после своих действий,  
чтобы понимать последствия принятых решений.**

## Описание

После выполнения действия игрок должен видеть:

- изменение ресурсов;
- изменение уровня смуты;
- изменение престижа;
- последствия для других игроков (если действие направлено на них).

Изменения должны отражаться в текущем состоянии королевства.


---

# US-7. Отслеживание текущего хода игры

## User Story

**Как игрок,  
я хочу понимать последовательность игровых действий,  
чтобы правильно взаимодействовать с механикой игры.**

## Описание

Игрок должен понимать порядок игрового хода:

1. происходит случайное событие;
2. отображаются его последствия;
3. игрок выбирает действие;
4. применяется результат действия;
5. начинается следующий ход.


---

# US-8. Контроль условий победы и поражения

## User Story

**Как игрок,  
я хочу понимать своё положение в игре,  
чтобы оценивать близость победы или поражения.**

## Описание

Игрок должен видеть показатели, влияющие на завершение игры:

- текущий престиж;
- уровень смуты;
- количество народа.

На основе этих данных игрок оценивает своё положение относительно условий окончания игры.


---

# US-9. Получение результата игры

## User Story

**Как игрок,  
я хочу получить информацию об окончании игры,  
чтобы понимать итог партии.**

## Описание

После достижения условий окончания игры система должна сообщить:

- победу игрока;
- поражение игрока;
- причину завершения игры.


---

# US-10. Понимание доступных стратегий

## User Story

**Как игрок,  
я хочу иметь несколько вариантов развития королевства,  
чтобы выбирать собственную стратегию достижения победы.**

## Описание

Игровая система должна позволять использовать разные подходы:

- экономическое развитие;
- развитие территории;
- дипломатическое взаимодействие;
- агрессивные действия;
- восстановление стабильности государства.

Игрок должен иметь возможность выбирать стратегию в зависимости от текущей ситуации.
