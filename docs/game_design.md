# Game Design Document  
## «Хроники Четырёх Земель»

## 1. Общая концепция игры

«Хроники Четырёх Земель» — многопользовательская пошаговая стратегия, в которой четыре игрока управляют собственными королевствами.

Игроки развивают свои территории, управляют ресурсами, реагируют на случайные события и взаимодействуют друг с другом через управляемые действия.

Каждый игровой ход состоит из двух этапов:

1. Неуправляемое событие — случайное событие, которое происходит автоматически и не зависит от выбора игрока.

2. Управляемое действие — действие, которое игрок выбирает самостоятельно и которое влияет на состояние своего или другого королевства.

Цель игры — развивать своё королевство, управлять ресурсами и достигнуть условий победы.


---

# 2. Игровые сущности

## 2.1 Игроки

В игре участвуют 4 игрока.

Каждый игрок управляет собственным королевством и принимает решения относительно использования ресурсов и взаимодействия с другими игроками.


---

# 3. Ресурсы королевства

Каждое королевство имеет пять основных показателей:

| Ресурс | Описание | Стартовое значение |
| --- | --- | --- |
| 🌾 Зерно | Еда, необходимая для развития и выживания | 10 |
| 💰 Деньги | Валюта для торговли и выполнения действий | 10 |
| 🏰 Земля | Территории, влияющие на развитие королевства | 5 |
| 👥 Народ | Население, рабочая сила и армия | 10 |
| 🔥 Смута | Показатель внутренней нестабильности | 0 |


---

# 4. Престиж королевства

Для оценки развития королевства используется показатель престижа.

Формула:
prestige = land * 2 + money // 5 + people // 5 - smuta


Где:

- land — количество земли;
- money — количество денег;
- people — количество народа;
- smuta — уровень смуты.


---

# 5. Условия победы и поражения

## Победа

Игрок побеждает, если выполняется одно из условий:

- престиж королевства становится равен или больше 30;
- игрок остаётся последним активным игроком.


## Поражение

Игрок проигрывает, если выполняется одно из условий:

- смута становится равной или больше 10;
- количество народа становится меньше или равно 0.


---

# 6. Общие ограничения игры

- значения ресурсов не могут стать отрицательными;
- смута не может быть меньше 0;
- игрок не может выполнить действие, если у него недостаточно ресурсов;
- действия с выбором цели требуют выбора другого игрока.


---

# 7. Структура игрового хода

Каждый ход состоит из двух этапов:

## Этап 1. Неуправляемое событие

Система случайным образом выбирает одно событие из списка.

Событие автоматически изменяет показатели королевства.


## Этап 2. Управляемое действие

Игрок выбирает одно доступное действие.

Если действие направлено на другого игрока, выбирается цель.

После выполнения действия изменяется состояние королевств.


---

# 8. Неуправляемые события

Неуправляемые события происходят автоматически и создают внешние условия, на которые игрок должен реагировать.


| ID | Название | Эффект | Тип |
| --- | --- | --- | --- |
| E1 | Засуха | -3 зерна | Отрицательное |
| E2 | Неожиданная прибыль | +5 денег | Положительное |
| E3 | Эпидемия | -3 народа, +2 смуты | Отрицательное |
| E4 | Урожайный год | +5 зерна | Положительное |
| E5 | Восстание крестьян | -2 зерна, +3 смуты | Отрицательное |
| E6 | Щедрый купец | +3 денег, +1 земля | Положительное |
| E7 | Торговый подъём | +2 денег, +1 зерна | Положительное |
| E8 | Пограничный конфликт | -2 народа, +2 смуты | Отрицательное |
| E9 | Развитие ремесла | +2 денег | Положительное |
| E10 | Политический кризис | +3 смуты | Отрицательное |

# 9. Управляемые действия игроков

Управляемые действия позволяют игроку самостоятельно изменять состояние игры.


| ID | Действие | Стоимость | Эффект | Ограничение |
| --- | --- | --- | --- | --- |
| A1 | Торговля | -3 деньги | Цель получает +4 зерна, игрок получает +3 деньги | Требуется выбор цели |
| A2 | Подкуп | -5 денег | Цель получает -2 смуты, игрок получает +1 землю | Не чаще 1 раза в 3 хода |
| A3 | Союз | -2 зерна | Оба игрока получают -1 смуты | Требуется выбор цели |
| A4 | Набег | -2 народа | Цель теряет -3 зерна, игрок получает +3 зерна и +1 смуты | Требуется выбор цели |
| A5 | Пропаганда | -3 деньги | Цель получает +1 смуты, игрок получает -1 смуты | Требуется выбор цели |
| A6 | Реформа | — | Игрок получает -1 смуты и +1 народа | — |
| A7 | Кража | Уточняется | Получение ресурсов другого игрока | Требуется выбор цели |


---

# 10. Принципы баланса игры

При проектировании игровых механик учитываются следующие критерии:

1. Действия не должны делать победу слишком простой.

2. Каждое действие должно создавать необходимость выбора.

3. Управляемые действия должны позволять игроку реагировать на последствия случайных событий.

4. Игровые механики должны быть реализуемыми с точки зрения алгоритма.

5. Разные стратегии развития должны оставаться конкурентоспособными.
